### Practice 09 · Featured analysis

**Which Iris measurements distinguish species better?**  
Using the UCI Iris dataset, I compared petal and sepal features with scatter plots and logistic regression on the same five stratified folds. Mean accuracy was **95.3% with petal features** and **81.3% with sepal features**. These results describe this dataset; performance on new flowers still needs testing.
